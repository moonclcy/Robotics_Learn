> **本页范围**:只关心"**力怎么进模型**"——力信号在网络内部放在哪、怎么编码、怎么和别的模态交互、以什么频率参与、能不能当预测目标。
> 姊妹页 [[force-aware-manipulation]] 从"力在**模仿学习**里当观测/预测/执行闭环"的谱系角度切入,与本页互补,细节(尤其 FoAR/FAWAM/CR-DAgger 的执行闭环)以那页为准。
> **前提约束**:用户无触觉传感器,本页只收**关节力矩 / 外置 6 轴力-力矩(wrench)**的工作,触觉(tactile)类不在范围。

## 一、完整思路:把"力进模型"拆成 5 个正交问题

给定一个预训练 VLA(几乎都是 π₀:VLM 编码器 + action expert 解码器 + flow matching),想加力,本质上要独立回答五件事。**这五个轴构成整个设计空间**,每篇论文都是在其中几个轴上做选择:

| 轴 | 问题 | 主要选项 |
|---|---|---|
| **① Source 力从哪来** | 用什么硬件拿到力 | 外置 6 轴 F/T(准、贵)· **电机电流反算关节力矩(无传感器、省)** · 触觉(排除) |
| **② Where 放模型哪里** | 力信号注入网络的哪一段 | conditioning **encoder** vs denoising **decoder/action expert**;VLM **前** vs **后** |
| **③ How 怎么编码/融合** | 力 token 怎么和别的模态交互 | 单 token vs 多 token;直接拼接 · **MoE 专家** · **每层 cross-attention 注入** · 门控加权 |
| **④ When/Freq 什么时间尺度** | 用哪个时刻的力、以什么频率 | 当前帧 / 历史窗口 / 预测未来;**单频 vs 双频(快-慢)+ 自适应频率** |
| **⑤ Objective 力还能当什么** | 力只当输入吗 | 当输入观测 · **当预测目标**(未来力矩 / wrench / 力波动)——预测式辅助任务 |

**跨论文的两条硬共识**(最值得记):
1. **晚融合(late fusion)**:力必须在预训练 VLM 处理完视觉-语言**之后**再进,别碰 VLM 前端表征。
   - TA-VLA:进 decoder 不进 encoder;ForceVLA:消融里 "MoE before VLM" 直接 **0%**。两篇殊途同归。
2. **力光"有"不够,得"会用"**:被动把力当额外观测,增益很小(ForceVLA:37.3→40.2 仅 +2.9;FAWAM:只加力观测 +7.5%)。大增益来自**会融**(MoE/门控/每层注入)或**预测未来力**。

**一条主要分歧**:力该和谁对齐融合?
- TA-VLA:力矩是**本体感受**,和关节角一家(HSIC=0.957),该进 decoder 跟 proprioception 融。
- ForceVLA:力该和**视觉-语言**在 MoE 里深度融合。
- 两者都成立,取决于你把力当"本体状态的延伸"还是"外部世界的感知"。

## 二、不同路线(按融合机制归类)

把已读的论文按"力进模型的核心机制"归成五条路线:

- **门控式 Gating** —— [[2411.15753-FoAR|FoAR]]:学一个未来接触概率 φ∈[0,1] 当软开关,`[hˢ; φ·hᶠ+(1−φ)·h*]` 动态加权力特征。核心洞察:**力是稀疏激活的**,非接触相要把力"关掉"。
- **位置式 Positional / 单 token** —— [[2509.07962-TA-VLA|TA-VLA]]:力矩压成**单个 token 进 decoder**;系统研究 where/how,结论"进 decoder、单 token、别破坏输入模式"。
- **专家式 MoE** —— [[2505.22159-ForceVLA|ForceVLA]]:**FVLMoE**,力 token 和 V-L 特征拼接后过稀疏 MoE(4 专家 top-1),再加回 action expert。
- **频率式 Fast-Slow** —— [[2602.23648-FAVLA|FAVLA]]:慢 VLM(低频语义)+ 快 action expert(高频力反应),**force adapter 每层 cross-attention 注入最新力**,再用预测的力波动**自适应调执行频率**。
- **预测式 Predictive**(与上面正交,可叠加) —— [[2606.08555-FAWAM|FAWAM]] 预测未来 wrench + 残差闭环;TA-VLA 辅助头预测未来力矩;FAVLA 的 force variance head 预测未来力波动并驱动频率。**共识:预测未来力 > 只当当前观测。**
- **训练式 Curriculum**(架构无关,可叠加到任何架构上) —— [[2502.17432-FACTR|FACTR]]:不改架构,用**课程训练**逼模型去用力——训练早期把视觉狠狠模糊,让策略只能靠力区分状态,再逐步解模糊。解决的是"**力塞进去了却被模型无视**"的问题(BC 会过拟合视觉)。

```
力进模型
├─ 当输入(How 之争,改架构)
│   ├─ 门控式  FoAR          "接触相才用力"
│   ├─ 位置式  TA-VLA        "进 decoder，单 token"
│   ├─ 专家式  ForceVLA      "MoE 融视觉语言"
│   └─ 频率式  FAVLA         "快-慢 + 每层注入 + 自适应频率"
├─ 当目标(Objective 之争,加辅助头)
│   └─ 预测式  FAWAM / TA-VLA辅助 / FAVLA方差头   "预测未来力"
└─ 怎么逼模型真去用力(改训练,架构无关)
    └─ 训练式  FACTR         "糊视觉的课程，逼注意力转向力"
```

> **第六个维度**:除了上表五轴(source/where/how/when/objective)都是"力怎么进"的**架构**问题,FACTR 点破还有一个正交问题——"**力进来了,怎么保证模型真的用它**"。BC 会偷懒过拟合视觉,于是需要训练侧的干预(课程)。这条与所有架构式路线**可叠加**。

## 三、逐篇总结卡片

> 维护约定:每读一篇新的"力进模型"论文,在此**加一张卡片**,并在第四节主表补一行、第五节勾掉候选。

### [[2509.07962-TA-VLA|TA-VLA]] · CoRL 2025 · 位置式 + 预测式
- **一句话**:系统研究"力矩往 π₀ 哪塞、怎么塞",给出可迁移的经验法则。
- **力进模型的方式**:关节力矩(电机电流反算,**无传感器**)→ **单 token 进 decoder**(不进 encoder);历史力矩压成一个 token;额外**预测未来力矩**当辅助目标。
- **关键结论**:进 decoder>encoder(HSIC:力矩↔关节角=0.957;decoder 对细微变化更敏感);历史压单 token>多 token(多 token 破坏 decoder 预训练输入模式)。
- **独特点**:唯一**无外置力传感器**的路线;把 where/how/when 做成显式消融。

### [[2505.22159-ForceVLA|ForceVLA]] · arXiv 2025-05 · 专家式
- **一句话**:用力感知 MoE(FVLMoE)把力和视觉-语言深度融合进 π₀。
- **力进模型的方式**:外置 6 轴 wrench → 投影成力 token → 和 V-L 特征拼接 → self-attn + 稀疏 MoE(4 专家 top-1) → guidance 逐元素加到 action expert。
- **关键结论**:**会融 > 有力**(直接拼力仅 37.3→40.2,FVLMoE 到 60.5);力必须 VLM 后进("MoE before VLM"=0%)。
- **独特点**:MoE 融合机制;视觉遮挡下靠力补(90%)。

### [[2602.23648-FAVLA|FAVLA]] · arXiv 2026-02 · 频率式 + 预测式
- **一句话**:力是高频信号,把 VLA 拆成慢 VLM + 快力反应 AE,并按预测的力波动自适应调频率。
- **力进模型的方式**:外置 6 轴 wrench,分**历史力(低频进 VLM)/ 最新力(高频进 AE)**两路;**force adapter 每层 cross-attention 注入**最新力;force variance head 预测未来力波动 → 决定 AE 每 chunk 跑几次。
- **关键结论**:自适应频率 > 任意固定频率;**峰值接触力显著更低**(Gear 7.7N vs π₀ 12.0N,更安全);同台**打赢 TA-VLA(62.3)、ForceVLA(67.0)**,平均 80.8%。
- **独特点**:唯一处理**频率/采样率不匹配**维度;唯一用"接触力大小"当指标。

### [[2411.15753-FoAR|FoAR]] · arXiv 2024 · 门控式(非 VLA,RISE 骨干)
- **一句话**:学未来接触概率 φ 当软开关,门控高频力融合 + 简单位置控制补偿。
- **力进模型的方式**:外置 6 轴 F/T → 用 φ 动态加权融合;非接触相用中性 embedding 把力关掉。
- **关键结论**:力稀疏激活,别全程混用;预测未来接触>检测当前。详见 [[force-aware-manipulation]]。

### [[2606.08555-FAWAM|FAWAM]] · arXiv 2026 · 预测式(世界模型骨干)
- **一句话**:世界模型联合预测动作 + 未来 wrench,用预测-实测力差值驱动残差闭环。
- **力进模型的方式**:force-conditioned AdaLN-Zero;把力从"观测"升级为"可预测的参考信号"。
- **关键结论**:预测未来 wrench 是单项最大杠杆(+17.5%),只当观测仅 +7.5%。详见 [[force-aware-manipulation]]。

### [[2502.17432-FACTR|FACTR]] · arXiv 2025-02 · CMU · 训练式(架构无关)
- **一句话**:架构不动,用"糊视觉再逐步解模糊"的课程,逼 BC 策略别过拟合视觉、真去用力。
- **力进模型的方式**:标准 ACT(视觉 token + 单力 token 进 encoder-decoder);力=机械臂**外部关节力矩**(自带,无外置传感器);创新在**训练课程**(σ 从大到小的视觉模糊)。
- **关键结论**:加力≠用力(纯加力 61.2%→加课程 87.5%,+40%);注意力可视化证明课程让"接触时注意力转向力";递减课程 > 固定模糊;有 NTK 理论支撑。
- **独特点**:唯一**架构无关、可叠加**的训练侧手段;唯一主打**未见物体泛化**。
